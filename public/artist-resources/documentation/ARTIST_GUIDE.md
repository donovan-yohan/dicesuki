# Legacy Dice Authoring Reference

This guide is retained for operator and historical reference only. The former
Artist Testing Platform and customer model upload workflow have been retired.
Do not direct customers to Settings or ask them to upload GLB files.

For current controlled releases, follow the repository's
[Dice Set Authoring guide](../../../docs/guides/dice-set-authoring.md). It is
the authoritative path for generating source material, validating assets,
publishing immutable versioned GLB paths, and promoting dice into the catalog
and shop.

The surrounding Blender templates remain useful when an operator needs to
inspect or reconstruct legacy geometry, but they are not a deployment or
submission mechanism.
