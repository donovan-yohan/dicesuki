# Operator Authoring References

These files are retained as historical and operator-reference material. They do
not provide a customer submission or in-app upload workflow: Dicesuki no longer
accepts customer-uploaded dice models.

Operators preparing a controlled dice release should use the current
[Dice Set Authoring guide](../../docs/guides/dice-set-authoring.md). That
pipeline produces validated authoring artifacts, immutable versioned GLB paths,
and catalog promotion inputs; it does not publish directly from this folder.

The Blender templates and older guide can still help inspect legacy geometry or
develop operator source material, but any release must pass the catalog and
runtime-asset validation gates before it is available in the shop.
